roastforge
resume and project roasting platform thing i made

what is this
basically a web app where u can upload resumes and projects and get them brutally reviewed by others. shows comments, votes, and all that good stuff
live here: https://roastforge-web.vercel.app/

features it has
user auth (login/register)
resume and project uploads
voting system (upvotes/downvotes)
comment threads on resumes
multi-level feedbacks

how to run
backend:
cd backend
npm install
npm run dev

frontend:
cd frontend
npm install
npm run dev
then open localhost:3000

usage
sign up for an account, go to the upload page to drop your resume. wait for people to rip it apart or give good advice.

tech
next.js + react + tailwind
node.js + express + typescript
mongodb for db
